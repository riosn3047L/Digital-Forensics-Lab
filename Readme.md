## Tools & Software Utilized

The following tools are used across the various experiments in this repository:
*   **FTK Imager**: Used for creating forensically sound images and previewing evidence without tampering.
*   **TestDisk**: Used for recovering lost partitions, fixing boot sectors, and undeleting files.
*   **Wireshark**: Used for capturing network traffic and analyzing unencrypted protocols (HTTP).
